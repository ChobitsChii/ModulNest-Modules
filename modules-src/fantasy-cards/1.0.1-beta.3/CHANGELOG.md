## 1.0.1-beta.2 - 2026-09-14

### Added
- Native v2 module structure for FantasyCards.
- Card sets overview and card set detail views.
- Booster claiming and opening system with interactive reveal animation.
- User collection view with rarity indicators and set completion progress.
- Admin management for sets, cards with inline editing, reordering, and mass upload (ZIP / image batch).
- Isolated schema migrations and demo seeds for native database setup.
- Package assets for frontend interactions (lightbox, booster animations, admin tools).
