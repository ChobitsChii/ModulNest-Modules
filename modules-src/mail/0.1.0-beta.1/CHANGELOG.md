## 0.1.0-beta.1 - 2026-09-14

### Added
- Native v2 module structure for Mail.
- Multi-account IMAP/SMTP management with encrypted credentials.
- Message list, search, sender groupings and folder statistics.
- Message detail view with safe iframe rendering and autosize support.
- E-Mail composer with multi-recipient support, HTML/Plain text and reply tracking.
- Favorite folders and sender whitelist management.
- Isolated schema migrations for native database setup.
